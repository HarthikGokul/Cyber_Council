CYBER COUNCIL WEBSITE - RUN GUIDE

1. Extract this ZIP file.
2. Keep index.html, style.css, script.js and the images folder together.
3. Double-click index.html to open it in Chrome or Edge.
4. The community section now contains eight image cards:
   Membership, Events, Resources, Get Involved, Chapters,
   Mentorship, Student Community and Social Impact.

No build step is required. Internet is only needed for the external Google Font.
